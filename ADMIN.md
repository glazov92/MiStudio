# ✏️ Админка MiStudio — руководство по использованию

Сайт салона красоты «Mi Studio». Все тексты, картинки, акции, услуги и портфолио
можно править прямо в браузере — без знаний вёрстки. Ниже — что нажимать,
как сохранять и как откатывать изменения.

<a name="как-войти"></a>
## 1. 🔐 Как войти в режим редактирования

В конце адреса сайта допишите `?edit=sLQSSJCRpwRrsdYSNhQR`:

```
https://ваш-сайт.ru/?edit=sLQSSJCRpwRrsdYSNhQR
```

Сайт — одностраничный лендинг, поэтому режим открывается на единственной
странице (все секции на ней).

Если ключ верный — внизу появится золотистая панель **«✏️ Режим редактирования»**,
а всё редактируемое на странице подсветится пунктирной рамкой.

> Ключ `sLQSSJCRpwRrsdYSNhQR` — технический (хранится в `config.js`). Это не защита от взлома,
> а «дверь с защёлкой»: на проде поставьте свой ключ.

**Выход** — кнопка **«Выйти»** в панели (убирает `?edit` из адреса).

<a name="панель"></a>
## 2. 🧭 Панель управления — что где

Панель закреплена внизу страницы и состоит из двух частей:

| Кнопка | Что делает |
| --- | --- |
| 💬 **Тексты** | Список всех текстов страницы — открыть редактор нужного |
| 🖼️ **Изображения** | Список всех картинок страницы — открыть замену любой |
| 🎯 **Акции** | Менеджер акций (добавить / изменить / удалить / отсортировать) |
| 🔧 **Услуги** | Менеджер услуг (добавить / изменить / удалить / отсортировать) |
| 📁 **Портфолио** | Менеджер работ (добавить / изменить / удалить / отсортировать) |
| 🔗 **Ссылки** | Соцсети (VK, Telegram) и онлайн-запись DiKiDi |

Правая часть — инструменты:

| Кнопка | Что делает |
| --- | --- |
| 💾 **Сохранить** | Явно сохранить всё в браузере (обычно правки сохраняются сами) |
| 📤 **Экспорт** | Скачать все изменения одним JSON-файлом (резервная копия) |
| 📥 **Импорт** | Применить ранее экспортированный JSON-файл |
| 🗑️ **Сбросить** | Удалить **все** правки разом (с подтверждением!) |
| **Выйти** | Покинуть режим редактирования |

<a name="текст"></a>
## 3. 💬 Редактирование текста

1. Войдите в режим редактирования (`?edit=sLQSSJCRpwRrsdYSNhQR`).
2. **Нажмите на текст** на странице — откроется окно «Редактировать текст».
3. Впишите новый текст и нажмите **«Сохранить»**.

Кнопка **«Сбросить к оригиналу»** появляется, только если этот текст уже
правился — возвращает исходную формулировку. **«Отмена»** закрывает окно без изменений.

Если не знаете, где текст на странице — откройте **💬 Тексты**: это список всех
редактируемых элементов с их текущим содержимым.

Телефоны редактируются так же (их два на сайте, `site_phone_0` и `site_phone_1`):
при сохранении автоматически обновятся все ссылки «позвонить» — в шапке, меню,
подвале и на странице контактов.

<a name="картинки"></a>
## 4. 🖼️ Редактирование изображений

Картинку можно заменить **двумя способами** — на выбор:

- **Загрузка файла с компьютера.** Нажмите «Выбрать файл» и укажите фото.
  Допустимый размер — до **3 МБ**. Картинка автоматически сожмётся
  (длинная сторона до 1600px, формат JPEG) и сохранится прямо в браузере.
- **URL.** Вставьте ссылку на картинку из интернета (например, из VK или
  фотостока) и нажмите **«Применить»**.

Заменять можно **любое** фото на сайте: главный экран (задний / центральный /
передний план), «О нас», карточки услуг, слайды на странице «Услуги», фото
мастеров, работы в галерее. Нажмите прямо на картинку (даже внутри открытого
попапа) или откройте список через **🖼️ Изображения**.

Кнопка **«Сбросить к оригиналу»** вернёт исходную картинку (если она менялась).

> ⚠️ Файл загружается в память браузера как текст (base64). У браузера есть
> лимит (~5 МБ на все данные сайта) — слишком большие фото могут не сохраниться.
> Поэтому «много фото в 3 МБ» не зальёшь — лучше ссылки из интернета или файлы
> поменьше. Сжимайте: логотипы и обложки — до 200–400 КБ.

<a name="акции"></a>
## 5. 🎯 Акции

Менеджер акций открывается кнопкой **🎯 Акции** в панели.

- **➕ Добавить акцию** — новая карточка в ленте.
- Клик по акции — редактирование полей:

| Поле | Что это |
| --- | --- |
| Бейдж | Плашка на карточке, например `−20%` |
| Метка | Короткая подпись, например «Новым гостям» |
| Заголовок | Название акции |
| Описание | Текст карточки |
| Примечание | Дополнительная строка |
| Текст кнопки | Надпись на кнопке, например «Записаться со скидкой» |
| Начало / Окончание | Даты действия (видны на карточке) |
| Акция активна | Галочка «показывать на сайте» — сняли, акция скрылась |

- **Удалить** — кнопка с крестиком на карточке акции.
- **Перетащите для сортировки** — зажмите карточку и двигайте, чтобы изменить
  порядок в ленте.

<a name="услуги"></a>
## 6. 🔧 Услуги

Менеджер услуг — кнопка **🔧 Услуги**. Открывается список категорий услуг;
клик по категории — полная форма редактирования (**«Добавить услугу»** — новая
категория, **«Редактировать»** — существующая).

Форма состоит из блоков, которые подписаны для наглядности:

- **Основное** — название категории, короткое описание, фото (слайды).
- **«Мастер»** — блок одного мастера: имя, фото (URL), описание.
  Кнопка **«+ Мастер»** — добавить ещё одного, крестик — удалить.
- **«Раздел прайса»** — категория цен внутри услуги (например,
  «Эстетическая косметология»). **«+ Позиция»** — новая строка цены.
- **«Позиция»** — процедура: название, примечание (длительность), цена.

После **«Сохранить»** услуга (или изменения в ней) появится на сайте сразу —
и на главной, и на странице «Услуги», без перезагрузки.

> Мелкие правки цен и описаний можно делать ещё быстрее: в режиме
> редактирования **нажмите на текст прямо в прайсе или попапе услуги** —
> откроется точечный редактор именно этой строки.

<a name="ссылки"></a>
## 8. 🔗 Ссылки и соцсети

Кнопка **🔗 Ссылки** — три поля: **ВКонтакте**, **Telegram** и **DiKiDi**
(онлайн-запись). Ссылки подставляются во все иконки соцсетей на сайте
(шапка, подвал, контакты).

Телефоны, адрес и часы работы отдельной кнопки не имеют — они правятся
**кликом прямо по тексту** на странице (см. раздел «Редактирование текста»).

<a name="сохранение"></a>
## 9. 💾 Сохранение и где живут данные

Правки **сохраняются сами** при каждом действии («Сохранить» в модалке,
добавление акции, замена картинки и т.д.). Кнопка **💾 Сохранить** в панели —
просто страховка «сохранить всё разом».

Данные лежат в браузере, в хранилище `localStorage`, по ключам
`mistudio_editor_*`:

| Ключ | Содержимое |
| --- | --- |
| `mistudio_editor_texts` | правки текстов |
| `mistudio_editor_images` | правки картинок |
| `mistudio_editor_service_paths` | точечные правки услуг |
| `mistudio_editor_promotions` | акции |
| `mistudio_editor_services` | услуги |
| `mistudio_editor_portfolio` | портфолио |
| `mistudio_editor_links` | соцсети |

**Важно:** данные привязаны к браузеру. С другого компьютера или телефона
ваших правок не видно — переносите их через экспорт/импорт (ниже).

> На хостинге с PHP-синхронизацией (`content-sync.php`) правки дополнительно
> сохраняются на сервере, и тогда они видны со **всех** устройств и **всем**
> посетителям — см. раздел «Хостинг».

<a name="резерв"></a>
## 10. 📦 Резервные копии: экспорт и импорт

- **📤 Экспорт** — скачивает файл `mistudio-editor-ГГГГ-ММ-ДД.json` со всеми
  изменениями. Держите такие файлы у себя — это бэкап и способ переноса правок.
- **📥 Импорт** — выберите этот JSON-файл: все правки применятся в текущем
  браузере, страница обновится.

Примеры использования:
- перенести правки с рабочего компьютера на другой;
- сохранить «снимок» перед большими экспериментами;
- передать разработчику, чтобы перенёс изменения в код сайта.

<a name="откат"></a>
## 11. ↩️ Откат изменений

Четыре уровня:

1. **Один элемент.** В окне редактирования текста/картинки — кнопка
   **«Сбросить к оригиналу»** (появляется, только если элемент правился).
2. **Одна сущность.** В менеджерах акций/услуг/портфолио можно удалить
   карточку (крестик) или убрать галочку «активна».
3. **Версия целиком (сервер).** Кнопка **🕘 История** в панели показывает
   сохранённые на сервере версии правок — по дате. Любая версия откатывается
   кнопкой **«↩️ Откатить»**. Перед откатом текущее состояние тоже
   сохраняется как версия, поэтому откат всегда можно отменить.
   (История работает, когда сайт развёрнут на хостинге; при открытии
   страницы с диска версий не будет.)
4. **Всё сразу.** Кнопка **🗑️ Сбросить** в панели удаляет **все** правки
   (тексты, картинки, акции, услуги, портфолио, ссылки) и перезагружает сайт
   к исходному виду. Спрашивает подтверждение — действие необратимо.
   Если нужен откат только «наполовину» — сначала сделайте **📤 Экспорт**.

<a name="хостинг"></a>
## 12. 🌐 Как изменения попадают на сайт (хостинг)

Правки в админке сохраняются в двух местах сразу:

- **в браузере** (localStorage) — быстро, работает даже офлайн;
- **на сервере** — автоматически через PHP-скрипт `content-sync.php`,
  если хостинг развёрнут по инструкции `DEPLOY-ADMINVPS.md`.

Поэтому на живом сайте все посетители видят ваши правки сразу после
сохранения: изменили текст → нажали «Сохранить» в модалке (или 💾 в панели) →
данные уехали на сервер → сайт обновлён для всех.

- Кнопка **💾 Сохранить** в панели явно публикует всё на сервер
  (сообщение «…опубликовано на сервере ✓»).
- Если сервер недоступен — правки останутся в браузере, и сайт покажет их
  только вам (сообщение «Сохранено локально…»). Когда сервер снова заработает,
  сохраните ещё раз — правки уедут на сайт.
- **🗑️ Сбросить** теперь удаляет правки и с сервера тоже (для всех посетителей).

> Резервная копия всё ещё нужна: на всякий случай раз в неделю жмите
> **📤 Экспорт** и храните JSON-файл у себя.

Подробный процесс запуска хостинга — в отдельной инструкции `DEPLOY-ADMINVPS.md`.

<a name="советы"></a>
## 13. 💡 Ограничения и советы

- **Режим инкогнито** — localStorage не работает, правки не сохранятся.
- **Лимит хранилища** (~5 МБ на браузер) — много картинок в base64 не зальёшь.
  Используйте URL-ссылки на фото и небольшие файлы.
- **Не меняйте `data-editable-id`** в HTML без причины — правки привязаны к этим
  идентификаторам, и после переименования старые изменения «не найдут» элемент.
- **Кеш-версия**: после правок разработчиком на страницах обновляется
  `?v=...` — если что-то не обновилось, обновите страницу (Ctrl+F5).
- **Проверяйте** внесённые изменения на главной, «Услуги», «Портфолио»
  и «Контакты» — часть контента показывается сразу на нескольких страницах.
- Если что-то сломалось — **📤 Экспорт** текущих правок и **🗑️ Сбросить**,
  затем импортируйте бэкап после устранения проблемы.
